## Installation

```bash
# Clone fork
git clone https://github.com/YOUR_GITHUB_USERNAME/hake-segmentation-inference.git

# Move into the cloned repo folder
cd hake-segmentation-inference

# Create conda environment
conda create -c conda-forge -n hake-segmentation-inference --yes python=3.12
conda activate hake-segmentation-inference

# Install package in editable mode
pip install -e .

# OR install package in editable mode including dev tools
pip install -e ".[dev]"
```
